Assalomu alaykum! 👋
Yakuniy darsimizda kodni modullarga bo'lish, loyihani professional
boshqarish — virtual muhit, paketlar va Git'ni takrorlaymiz.

Bugungi mavzular:

📦 1. Modul va paket ⭐ YANGI

  • Modul — .py faylni import qilish (import, from ... import, as)\
  • __name__ == "__main__" — nega kerak\
  • Paket — __init__.py bo'lgan papka\
  • Loyihani modullarga bo'lib tashkil qilish

📚 2. Standart kutubxonalar (loyihada eng ko'p ishlatiladiganlar)

  • os — papka, fayl yo'llari, muhit o'zgaruvchilari (env)\
  • pathlib — fayl yo'llari bilan zamonaviy, xavfsiz ishlash (Path) ⭐\
  • argparse — terminal (CLI) argumentlarini qabul qilish\
  • datetime — sana va vaqt (hisobot, log, timestamp)\
  • random — tasodifiy qiymatlar (test ma'lumoti, tanlov)

📌 3. Virtual muhit va tashqi paketlar

  • venv — virtual muhit nima va nega kerak\
  • uv bilan loyiha boshqaruvi (uv init / add / run)\
  • pip — klassik usul\
  • requirements.txt va pyproject.toml

🔐 4. Konfiguratsiya va maxfiylik

  • .env va environment variables (python-dotenv)\
  • .gitignore — token va parolni himoyalash ⭐ ENG MUHIM

🐙 5. Git asoslari

  • git init / add / commit / status / log\
  • Branch va merge bilan ishlash

☁️ 6. GitHub va portfolio

  • push / pull / clone\
  • Pull Request (PR)\
  • README.md va Markdown asoslari
