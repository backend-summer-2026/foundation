Bugungi mavzular:

📌 1. Asoslar (qisqa takrorlash)

  • O'zgaruvchilar va ma'lumot turlari (int, float, str, bool)\
  • Type conversion — turlarni o'zgartirish\
  • Operatorlar: arifmetik, taqqoslash, mantiqiy\
  • f-string bilan matn formatlash\
  • Shartlar (if / elif / else) va sikllar (for / while)\

📦 2. Ma'lumot strukturalari

  • String metodlari va slicing\
  • List — ro'yxatlar\
  • Tuple — o'zgarmas ketma-ketlik\
  • Dictionary (dict) — key-value ⭐ ENG MUHIM\
  • Set — takrorsiz to'plam\
  • Nested (ichma-ich) strukturalar = JSON ko'rinishi

⚡ 3. Comprehensions

  • List / dict / set comprehension\
  • Ma'lumotni tez filtrlash va o'zgartirish

🔧 4. Funksiyalar

  • def, parametr, return\
  • Default va keyword argumentlar\
  • *args va **kwargs\
  • Scope (local / global)\
  • lambda funksiyalari

🛡 5. Xatoliklar bilan ishlash

  • try / except / finally\
  • Exception turlari (ValueError, TypeError, KeyError...)\
  • raise — xatoni o'zi chaqirish\
  • Custom exception yaratish
