# 🔄 Kirish bloki — Takrorlash va Tayyorgarlik

> **Foundation → Backend.** Backend kursiga kirishdan oldin, Python poydevorini backend ehtiyojlari asosida qayta jonlantiramiz.

Bu blok — **Foundation** kursini tugatgan o'quvchilarni **Backend Development** kursiga to'liq tayyorlaydigan **3 darslik ko'prik**. Maqsad noldan o'rgatish emas — eng muhim bilimlarni *tez takrorlash* va butun guruhni bir chiziqqa keltirish.

Har bir dars backend'da aynan kerak bo'ladigan mavzularga urg'u beradi: `dict`/JSON, OOP, virtual muhit va Git.
